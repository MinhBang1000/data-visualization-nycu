Seoul District Pollution Patterns User Guide

This visualization provides insights into Seoul’s air pollution patterns across 25 districts and 6 pollutants (CO, NO₂, O₃, PM2.5, PM10, SO₂).

  • Select Year: Use the dropdown to view data for 2017, 2018, or 2019.
  • Number of Bands: Adjust the color bands to control the intensity levels displayed in each chart.
  • Toggle View: Switch between grid and stacked layouts for different views of the charts.
  • Hover for Details: Hover over each chart to see detailed daily pollution values, date, and band ranges.
  • Color Legend: Each pollutant has a unique color to make identification easy.

For optimal performance, avoid switching rapidly between years and bands. Reload the page if the application slows down.
